## Temas abordados

- **Fundamentos:** entrada/saída de dados, variáveis, operadores
- **Estruturas condicionais e de repetição:** `if/elif/else`, `for`, `while`
- **Manipulação de strings:** inversão, contagem de caracteres/vogais/palavras, palíndromos, anagramas
- **Listas e dicionários:** ordenação, soma, média, remoção de duplicatas, classificação de números
- **Algoritmos clássicos:** fatorial, Fibonacci, números primos, busca binária, bubble sort
- **NumPy:** arrays, operações vetoriais e matriciais
- **Pandas:** manipulação e análise de dados tabulares
- **Limpeza de dados:** tratamento de valores ausentes, inconsistências e viés de amostragem
- **Scikit-Learn:** construção de modelos simples de machine learning
- **Matplotlib:** visualização e plotagem de gráficos
- **SciPy:** funções científicas e estatísticas

## Projeto Summit — O Desastre de 1936

Em 1936, a revista *The Literary Digest* coletou 2,4 milhões de respostas e previu com "certeza absoluta" o resultado da eleição presidencial americana — e errou de forma catastrófica.

Nesta atividade, o desafio é investigar esse clássico erro estatístico como cientistas de dados forenses: usando Pandas, NumPy e Scikit-Learn básico, a equipe limpa os dados históricos, identifica a origem do viés de amostragem e constrói um modelo simples de correção capaz de "salvar" a previsão.

Os arquivos do projeto (planilha Excel com os dados e notebook `.ipynb` com a análise) estão na pasta `summit/`.

## Como executar

Abra os notebooks das pastas `exercicios/` e `summit/` diretamente no [Google Colab](https://colab.research.google.com/) ou no Jupyter Notebook local. Para o projeto Summit, mantenha a planilha Excel na mesma pasta do notebook para que a leitura dos dados funcione corretamente.
